Skills sind wiederverwendbare Anweisungen für AI Coding Agents. Sie definieren Workflows, Best Practices und spezifisches Wissen, das Agents bei wiederkehrenden Aufgaben unterstützen.

Verfügbare Skills

Wie Skills funktionieren

Skills leben im GitHub-Repo — die einzige Quelle der Wahrheit. Kein ZIP, keine Kopie, die auseinanderläuft. Agents laden Skills direkt aus dem Repository.

Installation für Claude Code

/plugin marketplace add Enterprise-AI-Circle/agent-skills
/plugin install <skill-name>@agent-skills

Installation für andere Agents

Gib deinem Agenten den Direkt-Link zum Skill-Ordner. Er lädt die SKILL.md und alle Referenzdateien automatisch.

"Installiere den Security-Audit-Skill von hier: https://github.com/Enterprise-AI-Circle/agent-skills/tree/main/agent-skills/security-audit"
